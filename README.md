# AI MAFIA

여섯 개의 서로 다른 로컬 AI가 추리하고, 거짓말하고, 투표하는 마피아 관전 실험실입니다. 인간은 플레이어가 아닌 관전자이며, **규칙과 승패는 Python 엔진이 결정**합니다. 실제 모델의 문체를 다른 모델로 재작성하지 않습니다.

React + TypeScript + Vite + Tailwind CSS / FastAPI + Pydantic / SQLite / Ollama HTTP API / SSE. 로컬 실행용 MVP이며 외부 배포는 하지 않습니다. 유료 LLM API를 사용하지 않습니다.

## 빠른 시작 (macOS)

필요: Python **3.11 이상**, Node.js **22.12 이상**, [Ollama](https://ollama.com), 충분한 모델 저장 공간. 개발 검증 환경은 Apple M3 / RAM 8GB / macOS 26.5.2 / Python 3.14.2 / Node 22.23.4 / Ollama 0.34.3입니다.

```bash
# 이 저장소 폴더에서
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
npm ci --prefix frontend
./scripts/start.sh
```

Finder에서 `start.command`를 실행해도 됩니다. 서버: **http://127.0.0.1:8000**. 스크립트가 프런트엔드를 빌드하고 백엔드가 제공합니다. `Control+C`로 스크립트가 시작한 서버를 종료합니다. 기존 Ollama 프로세스는 종료하지 않습니다. macOS에서는 실행 중 `caffeinate -i -s`로 유휴 시스템 잠자기를 방지합니다(덮개를 닫는 동작이나 전원 제약까지 보장하지 않습니다).

웹의 **관리자 연결 → 관리자 키 파일 불러오기**에서 `data/admin-token.txt`를 선택하세요. 키는 최초 백엔드 실행 시 무작위 생성되며 파일 권한은 600입니다. 관리자 키 파일·DB는 Git에서 제외합니다. 관전에는 관리자 키가 필요 없습니다. 현재 인증은 단일 로컬 관리자용 Bearer 키이며 인터넷 공개용 계정 인증은 아닙니다.

### 프런트엔드/백엔드 따로 실행

```bash
# 터미널 1: 필요 시 Ollama를 아래 설정으로 실행 (기존 서버와 중복 실행 금지)
OLLAMA_HOST=127.0.0.1:11434 OLLAMA_NUM_PARALLEL=1 OLLAMA_MAX_LOADED_MODELS=1 OLLAMA_KEEP_ALIVE=0 OLLAMA_NO_CLOUD=1 ollama serve

# 터미널 2
.venv/bin/python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000 --timeout-graceful-shutdown 5

# 터미널 3
npm run dev --prefix frontend
# http://127.0.0.1:5173, /api는 백엔드로 프록시
```

`.env.example`을 `.env`로 복사하면 시작 스크립트가 환경변수를 읽습니다. `ADMIN_TOKEN`을 생략하면 자동 생성 키를 사용합니다. 직접 uvicorn을 실행할 때는 환경변수를 직접 지정하세요. `AI_MAFIA_DATA`로 데이터 폴더를 바꿀 수 있습니다. 서버 작업자는 **1개**만 사용하세요. 여러 작업자를 실행하면 게임 메모리 상태가 분리됩니다.

## 참가 모델

| AI | 기본 태그 | 경량 대안 |
|---|---|---|
| DeepSeek | `deepseek-r1:7b` | `deepseek-r1:1.5b` |
| Gemma | `gemma3:4b` | `gemma3:1b` |
| Ministral | `ministral-3:3b` | 동일 |
| EXAONE | `exaone3.5:7.8b` | `exaone3.5:2.4b` |
| Qwen | `qwen3:4b` | `qwen3:1.7b` |
| Llama | `llama3.2:3b` | `llama3.2:1b` |

기본 모델 합계 약 20.4GB는 **디스크 크기**입니다. RAM 요구량이 아닙니다. 모델별 실제 요구량은 컨텍스트/양자화/시스템 상태에 따라 다릅니다. [Ministral 3 모델 안내](https://ollama.com/library/ministral-3:3b)는 Ollama 0.13.1 이상을 요구합니다. 웹의 **모델 실험실**에서 버전, 설치 태그, digest, 메모리를 확인합니다.

모델은 자동 다운로드하지 않습니다. 아래 명령을 필요한 만큼 직접 실행하세요.

```bash
ollama pull deepseek-r1:7b
ollama pull gemma3:4b
ollama pull ministral-3:3b
ollama pull exaone3.5:7.8b
ollama pull qwen3:4b
ollama pull llama3.2:3b

# 8GB에서 기본 모델 실행이 어려울 때 직접 선택할 경량 모델
ollama pull deepseek-r1:1.5b
ollama pull gemma3:1b
ollama pull exaone3.5:2.4b
ollama pull qwen3:1.7b
ollama pull llama3.2:1b
```

웹에서 모델을 참가자별로 바꿀 수 있습니다. 설치된 다른 로컬 태그도 선택할 수 있습니다. 모델 태그와 digest를 기록하며 자동 대체하지 않습니다. 실제 경기에는 서로 다른 태그 6개가 필요합니다. 같은 가중치의 별칭 태그를 여러 개 선택하지 않는 것이 좋습니다. 클라우드 모델 태그는 차단합니다.

## 게임 규칙

6명, 첫날 낮 시작. 낮 토론(기본 3라운드) → 선택적 전원 최후 변론 → 투표 → 처형 → 승패 확인 → 밤 비밀 대화/능력 → 결과 공개 → 승패 확인 → 다음 낮. 발언 순서는 회전 또는 무작위입니다. 최다 득표 동률은 처형 없음, 자기 투표·사망자 투표는 금지됩니다. 투표는 모두 선택한 뒤 동시에 공개하므로 뒤 순서 AI가 아직 공개되지 않은 투표를 볼 수 없습니다.

| 직업 | 진영 | 능력 |
|---|---|---|
| 마피아 | 마피아 | 밤에 시민 진영 생존자 공격 |
| 스파이 | 마피아 | 진영 비밀 대화 참여, 공격 불가, 경찰에게 시민으로 판정 |
| 경찰 | 시민 | 본인을 제외한 생존자 조사, 결과는 본인만 확인 |
| 의사 | 시민 | 본인 포함 1명 치료 |
| 경호원 | 시민 | 본인 제외 1명 보호, 대신 피격 |
| 시민 | 시민 | 토론·투표 |

밤 우선순위: 모든 능력 대상 선택 완료 → 경찰 조사 결과 본인에게 저장 → 의사가 공격 대상을 직접 치료했으면 공격 무효 → 그렇지 않으면 경호원이 보호 중일 경우 경호원 대신 피격 → 피격자가 치료 중이면 생존. 능력은 밤 시작 시 생존 기준으로 동시에 적용됩니다. 마피아 2명의 공격 선택 동률은 **공격 없음**이며 무작위 공격을 만들지 않습니다.

실제 마피아가 전멸하면 스파이가 살아 있어도 시민 승리. 실제 마피아가 생존하고 마피아 진영 인원이 시민 진영 이상이면 마피아 승리.

마피아 1~2명, 스파이 최대 1명, 마피아 진영 전체 최대 2명. 경찰·의사·경호원 각각 최대 1명. 기본 구성은 마피아/경찰/의사 각 1, 시민 3명이며 경호원·스파이는 비활성입니다. 활성화와 배정은 별개입니다. 기본/경호원/스파이 프리셋, 직접 배정, 구성한 직업 수를 유지하는 무작위 배정을 제공합니다.

## AI의 기억과 표현

- 공통 규칙, 본인 직업·허용된 진영 정보, 개인 조사 결과, 공개 사건, 주관적 개인 메모, 최근 발언을 각각 구분합니다.
- 다른 참가자의 비밀 직업을 공통 프롬프트에 넣지 않습니다. 확정 사실(투표/사망/조사)과 모델이 작성한 인상 메모를 구분합니다. 개인 메모는 사고 과정이 아닌 짧은 인상이며 공개하지 않습니다.
- 긴 공개 대화는 결정적으로 압축하고 최근 발언을 제한합니다. 전체 원문은 DB에 보존합니다. 아주 긴 게임은 2K 컨텍스트를 넘을 수 있어 예산 검사로 일시정지하며, 토큰 추정 오차가 존재합니다.
- 구조화된 응답의 `speech`를 그대로 표시합니다. 행동 대상은 서버가 검증하며 잘못된 선택은 제한 재요청 후 일시정지합니다. 무작위 행동을 모델의 선택처럼 기록하지 않습니다.
- Ollama `thinking` 필드를 저장·공유하지 않습니다. `<think>` 블록을 제거하고 닫히지 않은 내부 추론 블록은 공개하지 않습니다. 응답 예산이 내부 추론으로 소진되어 최종 발언이 없으면 오류로 처리합니다.

### Original / Character / Mixed

기본값 **Original AI Mode**는 말투 지침을 프롬프트에서 완전히 제외합니다. 모델별 고정 성격을 강요하지 않습니다.

**Character Theme Mode**는 참가자별 허구의 코미디 말투 자료만 덧붙입니다. DeepSeek 혁명 연설가, Gemma 테크 기업 발표자, Ministral 철학적인 귀족, EXAONE 사극 속 책사, Qwen 고대 병법가, Llama 서부 카우보이 프리셋을 제공합니다. 실제 국가/회사/모델의 성향을 주장하지 않습니다.

게임 설정에서 모드, 전체 연출 강도, 각 AI의 활성화/이름/설명/말투/어휘/금지 표현/개별 강도를 편집하고 저장할 수 있습니다. 기본값 복원을 지원합니다. 낮 토론·최후 변론·사망자 채팅·인터뷰가 같은 프롬프트 경로를 사용합니다. 출력은 해당 실제 모델이 생성하며 예시 대사를 삽입하지 않습니다.

경기 중 **진행 중인 경기에 말투 적용** 버튼으로 변경할 수 있습니다. 현재 추론은 기존 설정으로 끝내고 다음 요청부터 적용합니다. 발언별 실제 모드·설정 ID/버전·강도를 기록하며 이전 발언을 수정하지 않습니다. 경기 중 모드/스타일 변경은 Mixed로 분류하고 Original 비교에서 제외합니다. 설정 저장은 이후 경기에도 재사용됩니다.

### 사망자 채팅과 인터뷰

사망자 라운지는 별도 채널입니다. 사망 AI는 공개 대화와 자신의 기존 정보를 보고 관전평을 생성하며 생존자에게 전달하지 않습니다. 사망 이후 새 비밀 진영 대화는 전달하지 않습니다. 하루 1인당 반응 상한(기본 1회)을 적용합니다. 종료 인터뷰는 선택 사항이고, 공식 결과와 전체 직업 공개 후 동일 모델이 자신의 판단을 설명합니다. 인터뷰는 승패를 바꾸지 않습니다.

## 기록과 통계

SQLite(`data/mafia.sqlite3`)에 설정, 참가자 태그/digest, 실제 역할, 개인 메모, 대화 채널, 투표, 밤 행동, 조사, 사망, 결과, 인터뷰, 스타일 변경 및 호출 지표를 저장합니다. DB 자체는 로컬 비밀 데이터이며 Public 저장소에 포함하지 않습니다.

통계는 **정확한 태그 + digest**별로 집계합니다. 전체/진영/직업 승률, 표본 수, 평균 생존 일수, 최종 생존율, 실제 마피아 투표 정확도와 표본, 경찰 조사 성공, 평균 응답 시간·토큰 속도·발언 길이를 제공합니다. Original/Character/Mixed를 분리합니다. 완료된 실제 Ollama 경기만 반영하며 Mock·중단·무효·서버 재시작으로 중단된 경기는 제외합니다. 인터뷰 도중 중단하더라도 이미 확정된 게임 결과는 유지합니다.

연속 대전 1/5/10/20/사용자 지정, 한 번에 한 경기, 직업 순환을 지원합니다. 6경기 주기로 각 참가자가 동일한 직업 구성을 경험합니다. 경기 기록 화면에 공개 다시보기를 제공합니다. 원문·선택은 그대로 재생하고 생존자 카드는 현재 **최종 상태**를 표시합니다.

서버 재시작 후 완료 기록은 유지됩니다. 진행 중 경기는 interrupted로 분류하며 자동 재개하지 않습니다.

## 8GB 메모리 정책과 검증 상태

한 번에 하나의 앱 추론만 실행합니다. 다른 태그의 모델이 로드돼 있으면 새 추론을 보류하고, 같은 모델 한 개는 재사용할 수 있습니다. `keep_alive:0`, 기본 컨텍스트 2048, 출력 예산 제한, 모델 해제 확인, 시간 제한, 제한적 재요청, 자동 실행 2시간 상한을 적용합니다. 자동 진행/일시정지/계속/한 단계/중단을 지원하며 revision과 실행 잠금으로 중복 단계를 차단합니다.

[Ollama API](https://docs.ollama.com/api/chat)의 `load_duration`, `eval_count`, `eval_duration`와 스트림 도착 시간을 사용해 로딩/첫 토큰/첫 최종 출력/전체 시간/초당 토큰을 기록합니다. 시스템 메모리를 0.5초 간격으로 측정합니다. 이는 GPU 전용 메모리나 모델별 정확한 사용량 측정이 아니라 시스템 전체 관측값입니다. 기존 스왑이 발생 원인인지는 단일 스냅샷으로 단정할 수 없습니다.

현재 정책은 경고와 비상 중지를 구분합니다. 파일 크기 기반 예상량 부족이나 OS warning은 실험실에서 확인 후 **위험을 감수하고 1회 실행**할 수 있습니다. 이 예외는 한 모델/한 프롬프트/재시도 0회에만 적용되며 게임이나 이후 요청에는 저장되지 않습니다. 기존 스왑 2GiB 초과만으로 차단하지 않습니다. OS critical, 가용 ≤0.20GiB 등 비상 조건은 우회할 수 없습니다. 실행 중에도 0.5초 간격으로 감시합니다.

실험실에서는 모델별 개별 측정·다중 모델 순차 측정·로딩/추론/언로드 상태·중단 버튼을 제공합니다. 실행 전 보류, 실제 실패, 사용자 중단, 실행 중 안전 중지, 성공을 따로 기록합니다. 다른 모델의 보류가 경량 모델 측정을 막지 않습니다.

**실제 검증:** Llama 3B는 전체 6.205초 / 38.74 token/s / 생성 128토큰으로 성공하고 언로드했습니다. DeepSeek 7B는 경고 확인 후 로딩을 시도했으나 약 2.179초에 OS critical이 감지돼 안전 중지·언로드했습니다. 성공으로 기록하지 않습니다. Llama 출력은 토큰 제한으로 잘렸고 일부 외국어가 섞였습니다. 실제 6모델 경기 완주, 캐릭터 품질과 장시간 안정성은 여전히 미검증입니다. 자세한 기준·수치·한계는 [메모리 실험 보고서](docs/MEMORY_EXPERIMENTS.md)에 기록했습니다.

```bash
./scripts/check.sh
# 또는
.venv/bin/python -m pytest -q
npm test --prefix frontend
npm run typecheck --prefix frontend
npm run build --prefix frontend

# 선택적 실제 Ollama 통합 테스트 (명시적 실행, 다운로드 없음)
RUN_OLLAMA_TESTS=1 .venv/bin/python -m pytest -q -m ollama
```

단위 테스트는 승패/직업 유효성/스파이 위장/의사·경호원 상호작용/동률, 정보 격리/말투 계층, 인증/API/revision, 일시정지/중복 단계, Mock 경기 완주/사망자/인터뷰, 통계·기록·직업 순환을 검증합니다. Mock 출력은 `[MOCK 기능 테스트]`로 명시하며 공식 통계에서 제외합니다. 실제 Ollama 테스트는 기본 실행에서 건너뜁니다. 세부 결과는 [검증 보고서](docs/VALIDATION.md)를 참고하세요.

## 게임 시작 오류 안내

정상 설정인데도 시작이 막히면 오류 패널의 원인을 확인하세요. 필수 필드/직업 구성 문제는 HTTP 422, Ollama 연결·설치·메모리 문제는 HTTP 503으로 구분합니다. 오류에는 수정할 항목이나 모델 실험실에서 확인할 방법이 표시됩니다. 심각한 압박은 우회할 수 없으며, 실험실의 경고 확인 후 1회 실행은 게임에 자동 적용되지 않습니다. 모델도 자동 교체하지 않습니다. 상세 재현과 검증은 [시작 오류 조사](docs/START_ERRORS.md)를 참고하세요.

## 보안과 인터넷 배포 계획

- 브라우저는 백엔드만 호출합니다. Ollama 11434를 외부에 공개하지 마세요.
- 모든 변경/개인 기록/전체 게임 원본 API는 관리자 Bearer 키를 검증합니다. 관전자 상태·SSE·다시보기는 서버에서 비밀 필드를 제외합니다. CSS 숨김을 보안으로 사용하지 않습니다.
- 제한된 CORS/허용 Host, API 입력 검증, 기본 보안 헤더를 제공합니다. React 텍스트 렌더링으로 모델 발언을 처리하며 HTML 삽입하지 않습니다.
- AI의 말과 캐릭터 설정은 게임 데이터이며 엔진 코드를 실행하거나 규칙을 바꿀 수 없습니다. 표현 속에서 모델이 공개 정보를 잘못 주장하는 것은 게임의 일부이며 서버 비밀 유출과 구분해야 합니다.
- `.env*`, 관리자 키, DB/WAL, 로그, 모델 파일, 의존성, 캐시, 빌드 결과는 Git에서 제외합니다. `.env.example`에는 비밀값이 없습니다.
- 인터넷 공개 전 TLS/계정 인증/요청 제한/프록시/백업/단일 작업자 감독이 더 필요합니다. 현재 로컬 관리자 키만으로 공용 서비스를 운영하지 마세요.
- MacBook이 꺼지거나 잠들면 게임 서버와 추론이 중단됩니다. 프런트엔드를 외부에 배포해도 로컬 AI Runtime은 계속 켜져 있어야 합니다.

구체적인 확장/캐릭터 인터페이스와 배포 준비 항목은 [FUTURE_FEATURES](docs/FUTURE_FEATURES.md)를 참고하세요.

## 현재 한계

- 실제 6개 모델 완주와 한국어·전략·캐릭터 품질은 아직 확인하지 못했습니다. Llama 3B의 단일 추론 성공과 DeepSeek 7B 안전 중지는 별도 기록했습니다.
- 8GB에서 7~8B가 안정적이라고 보장하지 않습니다. 실제 7B 로딩 시 심각한 압박으로 자동 중지된 사례가 있습니다.
- 2048 컨텍스트에서 긴 경기의 모든 발언 원문은 유지할 수 없습니다. 최근 발언과 확정 사건, 짧은 개인 인상 메모를 사용합니다. 토큰 추정치는 정확한 모델별 토크나이저 결과가 아닙니다.
- 중단 경기는 자동 재개하지 않습니다. SQLite 스냅샷 저장 방식은 로컬 MVP용이며 대규모 동시 관전/다중 작업자는 지원하지 않습니다.
- 리플레이 카드의 과거 시점 복원, 실험실의 Character A/B 품질 비교, CSV 내보내기, 전용 모델별 경기 필터는 후속 작업입니다.
- 연속 대전은 자동 진행에서 다음 경기를 생성합니다. 수동 단계는 현재 경기만 진행합니다.
