# 검증 보고서

검증일: 2026-11-07~08 (Asia/Seoul). 실제 로컬 검증과 Mock 검증을 구분한다.

## 구현 범위

- 6개 기본/경량 모델 태그, 설치 목록, 개별 모델 선택, Ollama 버전·메모리 점검
- 직업 6종, 설정 검증, 낮/밤/동시 투표, 의사·경호원 우선순위, 스파이 위장 조사, 엔진 승패 판정
- 순차 Ollama 스트리밍, 요청 제한, 재요청, keep_alive=0, 해제 확인, 추론 중 메모리 압박 감시
- 본인 확정 비밀/공개 사실/주관적 메모 분리, 개인별 프롬프트, 내부 추론 비공개
- 일시정지/계속/한 단계/중단, 중복 단계 차단, 자동 연속 경기, 6경기 직업 순환
- Original/Character 모드, 6개 가상 프리셋 편집·저장·복원·개별 비활성화, 경기 중 전환과 Mixed 기록
- 다크 관전 UI, 사망자 라운지, 결과 직업 공개, 인터뷰, 공개 로그 다시보기
- SQLite 기록, 완료 실제 경기만 통계, 태그+digest 구분, 모드별/진영별/직업별 승률과 표본 수
- 관리자 Bearer 인증과 서버 응답 정보 격리, 제한된 CORS/Host, 안전한 텍스트 렌더링

최종 자동 테스트: **57 passed, 7 skipped**. 실제 Ollama opt-in 실행: **1 passed, 6 skipped**. 프런트엔드 타입 검사·빌드와 시작 스크립트 문법 검사 통과. 시작 스크립트의 실제 localhost 실행도 확인했다. 테스트 구성:

| 구분 | 확인 항목 |

| 에이전트 | 본인 비밀만 전달, 다른 개인 메모 비공개, 죽은 자에게 새 진영 대화 차단, Original 말투 계층 없음 |
| 제어 | 일시정지 안전 지점, 진행 중 스타일 변경은 다음 요청부터, stale revision, 동시 단계 차단, 오류 시 가짜 선택 없음 |
| Mock 통합 | 실제 모델 6개로 위장하지 않는 명시적 테스트 출력, 경기 완료, 사망자 반응, 6인 인터뷰, 순차 연속 경기 |
| 저장/통계 | 재시작 기록 유지, 중단 경기 복구 분류, Mock/중단 제외, Original/Character/Mixed 분리, digest별 통계 |
| API | 관리자 필요, 잘못된 입력 거절, 공개 상태·리플레이에서 역할/밤 행동/개인 메모 비공개 |
| Ollama 어댑터 | Mock HTTP 스트림의 thinking 비저장, legacy think 제거, 지표 산출, keep_alive=0, 순차 요청, 불완전 스트림도 해제 |

## 설치 상태와 실제 추론

Ollama 0.34.3. 지정한 기본 모델 6개 모두 설치 확인. 이 프로젝트는 모델 다운로드를 수행하지 않았다. 검증 중 외부에서 설치 목록이 갱신된 사실만 확인했다.

| 모델 | 설치 | 실제 응답 검증 | 사유 / 속도 |
|---|---|---|---|
| deepseek-r1:7b | 있음 | 보류 | 기존 스왑 2GiB 초과 / 미측정 |
| gemma3:4b | 있음 | 보류 | 가용 메모리 부족 / 미측정 |
| ministral-3:3b | 있음 | 보류 | 가용 메모리 부족 / 미측정 |
| exaone3.5:7.8b | 있음 | 보류 | 기존 스왑 2GiB 초과 / 미측정 |
| qwen3:4b | 있음 | 보류 | 가용 메모리 부족 / 미측정 |
| llama3.2:3b | 있음 | 보류 | 가용 메모리 부족 / 미측정 |

경량 대체 태그는 설치하지 않았으며 임의 교체하지 않았다. 기본 태그 외에 기존 deepseek-r1:8b, deepseek-r1:latest, gemma3:latest, llama3.2:latest, mistral:latest도 설치 목록에서 확인했다.

Mac RAM 8GiB. 첫 조사 시 기존 스왑 약 2.57GiB, 이후 약 3.6~3.8GiB. 모델 점검 시 가용 약 1.7~1.8GiB였다. 이 수치는 **추론 전부터 존재한 시스템 전체 상태**이며 새 게임 실행이 발생시킨 메모리 사용이라고 주장하지 않는다. 7~8B 실제 로드 스트레스 테스트는 수행하지 않았다. 여섯 모델의 생성 시간/토큰 속도/한국어 자연스러움/전략 차이/말투 강도 준수는 미검증이다. 실제 출력 예시는 없다.

실제 모델 측정 기능 자체는 UI와 `scripts/benchmark.py`로 제공한다. 자원을 확보한 뒤 사용자가 실행할 수 있다. 6가지 동일 상황 테스트도 구현했지만 실제 출력·질적 평가는 미검증이다. Original/Character 프롬프트 차이와 캐릭터별 격리는 Mock/단위 테스트로 검증했다.

## 브라우저 확인

로컬 정적 앱의 HTTP 응답과 실제 Chrome 초기 대시보드 렌더링을 확인했다. 관전자 화면에서 6개 실제 모델 태그와 비공개 직업 표시, 설치 여부, SSE 연결 상태가 보였다. 초기 내장 미리보기 탭이 소멸하는 문제가 있었고, 이후 브라우저 제어 중 사용자 포커스 변경으로 추가 조작 검증을 중단했다. 모든 모바일 크기와 모든 관리자 UI 상호작용을 브라우저로 완주했다고 주장하지 않는다. 관리자/말투/제어의 API는 자동 테스트로 검증했다.

## 공개 업로드 원칙

데이터 폴더(관리자 키·DB·로그), 환경 파일, 모델 파일, 의존성, 가상환경, 캐시, 빌드 출력, 로컬 상세 보고서는 Git에서 제외한다. Git 인덱스 및 모든 도달 가능한 이력 blob에 대해 제외 경로·대표 인증 토큰 패턴·현재 로컬 관리자 키를 검사한다. 비밀값 자체를 검사 로그에 출력하지 않는다. 공개 커밋 작성자는 GitHub noreply 주소를 사용한다. 검사 범위가 모든 가능한 종류의 비밀정보 탐지를 보장하는 것은 아니므로 파일 목록과 소스도 함께 검토한다.
