# AI MAFIA 확장 설계

## 현재 캐릭터 계층

Original(기본), Character, Mixed의 데이터 경로를 분리했다. 게임 엔진은 말투를 참조하지 않는다. `prompts.py`의 공통 규칙 → 본인 비밀 정보 → 확정 공개 기록/주관적 메모 → 현재 행동 요청 → 선택적 말투 자료 순서로 구성한다. Original에서는 말투 자료를 아예 추가하지 않는다.

Character 프리셋은 허구의 코미디 설정이다. 실제 국가·국민·회사·모델의 정치적 성향을 뜻하지 않는다. 참가자별 ID·버전·활성화·이름·설명·지침·어휘·금지 표현·강도를 저장한다. 전체 연출 강도와 개별 강도를 별도로 전달한다. 말투 강도 준수는 모델의 지시 이행 능력에 달려 있으며 품질 검토가 필요하다.

경기 중 설정 변경 시, 진행 중인 요청은 기존 설정의 복제본을 사용한다. 다음 요청부터 새 설정을 적용한다. 이전 발언을 수정하지 않는다. 발언과 호출 기록에 실제 모드/캐릭터 버전/강도/적용 여부가 남고, 관리자 로그에는 변경 설정의 복제본이 남는다. 전환이나 경기 도중 스타일 편집이 있으면 Mixed로 분류한다. Original/Character/Mixed 통계는 따로 집계한다.

## 다음 개선

- 캐릭터 프리셋 저장소, 설정 내보내기/가져오기와 동일 seed A/B 실험
- 캐릭터 모드 동일 상황 테스트를 UI에서 직접 비교 (현재 동일 상황 실험실은 Original 기준)
- 모델별 실제 토크나이저를 이용한 컨텍스트 예산 검증; 현재는 확정 사실을 보존하는 결정적 압축과 최근 발언 창을 사용하며 예산을 넘으면 안전하게 중단
- 공개 발언별 인용 링크, 리플레이 시점의 생존자 카드 복원
- 경찰 조사 성공, 투표 정확도 외에 시계열 전략 분석; 근거 없는 성격 점수화는 피한다
- 완료 경기 결과 CSV 내보내기, 모델별 기록/추론 설정 비교 필터
- 새 직업은 Role 레지스트리와 엔진 능력 처리/우선순위 표를 통해 확장
- 중단 경기의 안전한 재개와 별도 배치 작업자, 작업 큐, DB 스키마 마이그레이션

## 인터넷 관전

프런트엔드 정적 빌드를 Vercel/Cloudflare Pages로 옮길 수 있다. FastAPI와 AI Runtime은 분리되어 있고 브라우저는 FastAPI만 호출한다. SSE는 공개 데이터만 전송한다. Ollama는 반드시 127.0.0.1:11434에 둔다. 외부 관전 터널은 백엔드 또는 별도 공개 읽기 전용 게이트웨이만 대상으로 해야 한다. 11434 포트를 터널로 열지 않는다.

실제 공개 서비스 전 추가할 것:

1. TLS, 관전자 접근 정책, 사용자/관리자 계정 인증, 키 회전, 로그인 속도 제한
2. 관리자 API를 별도 네트워크나 접근 제어로 보호; 현재 단일 로컬 Bearer 키는 다중 사용자 인증이 아니다
3. 배포 도메인에 맞춘 명시적 CORS/ALLOWED_HOSTS; 와일드카드 금지
4. SSE 연결 수 제한, 역방향 프록시 timeout/buffering, DB 백업과 접근 로그의 비밀값 제거
5. 프로세스 감독, 작업자 1개, 모니터링과 게임 복구, 데이터 보관/삭제 정책
6. 모델 라이선스 검토 (특히 EXAONE)와 공개 AI 발언의 운영 정책

현재 외부 배포/유료 API 연결/터널 생성은 하지 않았다. MacBook이 꺼지거나 잠들면 로컬 서버 및 추론도 중단된다.
